# PanelMate 开发计划

## 1. 文档信息

- 项目名称：`PanelMate`
- 文档版本：`V2.5`
- 更新日期：`2026-04-25`
- 当前策略：`仅支持 1Panel V2 API`

## 2. 开发目标

1. 维持纯前端架构，不引入中转后端。
2. 所有业务链路统一基于 `V2 API`。
3. 概览页作为服务器主入口，聚合搜索、筛选、列表和进入详情流程。
4. 通过独立 `AI` Tab 承接 AI 模块展示与扩展入口。
5. 首页与详情页展示动态实时数据。
6. 轮询设置必须真实生效并持久化。
7. 保证连接配置与凭证安全存储。
8. 去除告警中心、应用内提醒和历史兼容链路。
9. 支持清新毛玻璃主题、内置渐变主题和自定义调色板。

## 4. 代码结构

```text
app/lib/core/panel/
  contracts/        抽象接口
  factory/          API 组合与会话工厂
  models/           连接模型、错误模型、能力标记
  probe/            连接测试结果
  runtime/          实时概览与轮询相关
  storage/          本地配置与凭证存储
  v2/               1Panel V2 API 适配层
app/lib/features/
  home/             首页壳层与 3 Tab 导航
  overview/         服务器总览主入口
  ai/               AI 工作台与模块展示
  servers/          服务器接入与详情
  operations/       操作日志服务
  modules/          容器/网站/应用/数据库/文件/备份
  settings/         安全、轮询与主题设置
```

## 5. 关键实现约束

1. `PanelApiVersion` 只保留 `v2`。
2. `PanelRuntimeService` 只走 V2 概览接口。
3. `PanelApiFactory` 只实例化 `v2/*` 实现。
4. 本地配置统一使用 `panelmate.*` 存储 key，不再读取旧项目 key。
5. 概览页只保留一个服务器主入口实现，不再维护独立列表页。
6. 概览页顶部不再保留大面积统计 Hero 或独立统计卡片区。
7. 筛选条必须保留 `全部 / 在线 / 离线` 筛选。
8. `新增服务器` 必须通过标题区右上角 `+` 进入。
9. AI 页当前以模块展示和入口预留为主，不承载服务器管理逻辑。
10. 主题选择必须通过设置页弹出调色板完成。
11. 自定义主题只保存颜色配置，不保存实时业务数据。

## 8. 风险

1. 纯前端直连依赖面板开放 CORS 或本地代理。
2. 自签名证书会影响浏览器联调。
3. V2 OpenAPI 文档与真实返回字段可能存在差异，需要按联调结果修正。
4. AI 工作台后续能力若接入真实模型服务，可能带来额外鉴权与成本问题。
