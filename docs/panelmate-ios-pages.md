# PanelMate iOS 页面说明

## 1. 文档信息

- 项目名称：`PanelMate`
- 文档版本：`V2.6`
- 更新日期：`2026-05-04`
- API 范围：`仅使用 1Panel V2 API`

## 2. 页面结构

底部导航采用 3 个 Tab：

1. `概览`
2. `AI`
3. `我的`

说明：

1. `概览` 是服务器相关操作的主入口。
2. 原独立 `服务器` Tab 已移除，不再保留单独服务器列表页。
3. `AI` Tab 用于承接 AI 功能模块展示与后续扩展。

## 3. 页面定义

### 3.1 添加服务器页

字段：

1. 服务器名称
2. 地址
3. 协议
4. 端口
5. EntranceCode
6. 登录方式
7. 账号 / 密码 或 API Key
8. 备注
9. 标签

交互：

1. 固定按 `V2 API` 做连接测试。
2. 账号密码模式在测试时先请求 `/core/auth/setting`，读取 `panel_public_key` 后加密密码，再请求 `/core/auth/login`。
3. 账号密码登录成功后缓存 session cookie 与 CSRF token；API Key 模式继续使用 `1Panel-Token` 与 `1Panel-Timestamp`。
4. 测试通过后展示 V2 能力检查结果。
5. 只有测试通过后才允许保存。
6. 保存成功后回到 `概览` 页，并将新服务器插入列表顶部。

### 3.2 概览页

定位：

1. 作为服务器总览、搜索、筛选和进入详情的主入口。
2. 首屏优先突出搜索与服务器列表，不再保留大面积顶部概览 Hero 区域。

内容：

1. 页面标题区：`概览` 标题、状态摘要文案、右上角 `+` 新增按钮。
2. 搜索框。
3. `全部 / 在线 / 离线` 筛选条。
4. 服务器卡片列表。
5. 无服务器或搜索无结果提示。

交互：

1. 搜索框支持按服务器名称、地址、标签过滤。
2. `全部 / 在线 / 离线` 作为可点击筛选项，支持与搜索组合使用。
3. 点击右上角 `+` 进入添加服务器流程。
4. 服务器卡片点击进入 `服务器详情页`。
5. 服务器卡片右侧操作菜单提供编辑与删除。

列表规则：

1. 不展示旧的大 Hero 卡片。
2. 不展示独立统计卡片区。
3. 不展示内嵌式 `新增服务器` 条目。
4. 新增服务器入口固定为标题区右上角 `+`。
5. 搜索结果为空时展示空状态卡片。

服务器卡片字段：

1. 服务器名称
2. 地址
3. 健康状态
4. API 标记
5. 认证方式
6. 分组标签
7. CPU / 内存 / 磁盘
8. 最后同步时间

### 3.3 服务器详情页

内容：

1. 顶部健康卡片
2. 实时资源区
3. 模块入口区
4. 最近操作
5. 接口能力摘要

实时资源字段：

1. CPU
2. 内存
3. 磁盘
4. 上行速率
5. 下行速率
6. 负载

顶部健康卡片字段：

1. 服务器名称
2. 地址
3. 健康状态
4. API 标记 / 认证方式 / 分组
5. 运行时长
6. 最后同步时间

### 3.4 AI 页

定位：

1. 作为底部导航第二个主入口。
2. 用于展示 AI 功能模块与后续扩展方向。

内容：

1. AI 工作台头图
2. 模块状态标签
3. AI 功能卡片列表

当前展示模块：

1. 智能巡检
2. 日志问答
3. 变更建议

说明：

1. 当前阶段以模块展示和入口预留为主。
2. 不在 AI 页承担服务器列表、搜索或筛选职责。

### 3.5 我的页

内容：

1. 主题样式
2. 安全设置
3. 轮询设置
4. 产品说明
5. 版本信息

说明：

1. 主题样式展示当前渐变主题，点击后弹出调色板。
2. 调色板内置 `薄荷清晨 / 海盐蓝 / 青柠花园 / 晨曦苏打`。
3. 调色板提供 `自定义` 入口，可分别选择主色、辅色和点缀色。
4. 主题配置会影响全局背景渐变、主色、底部导航、按钮和卡片强调色。
5. 主题配置与自定义颜色会本地持久化，页面刷新或重启后保留。
6. 安全设置包含 `启用应用锁 / 后台自动模糊 / 自动锁定时间` 三项，开关切换即时持久化。
7. 自动锁定时间支持 `关闭 / 1m / 5m / 15m / 30m`，默认 `5m`，应用锁开启时前台闲置或从后台返回超过该时长会弹出锁定遮罩。
8. 后台自动模糊开启时，应用切到后台或处于任务切换状态会覆盖一层模糊遮罩遮挡敏感内容。
9. 轮询设置为真实生效配置，支持 `1s / 5s / 10s / 15s / 关闭`，默认 `10s`。
10. 轮询配置变更后会影响前台自动刷新行为，并在页面刷新后保留。

## 4. 视觉与交互原则

1. 概览页首屏优先保证搜索入口可见。
2. 顶部不再保留大面积概览 Hero 或独立统计卡片区。
3. 新增服务器入口使用标题区右上角 `+`，避免占用列表内容区域。
4. 高风险操作必须二次确认。
5. 不再提供告警中心与应用内提醒入口。
6. 主题选择使用底部弹出调色板，避免在设置页直接展开大量选项。
7. 自定义主题使用预设色板选择，不在当前阶段提供自由输入色值。

## 5. 说明

1. 当前页面设计不再提供 V1 / V2 切换入口。
2. 所有接口说明、字段映射和调试策略均以 V2 为准。
3. 页面结构已同步当前实现，不再包含独立服务器列表页。
4. 当前视觉方案采用毛玻璃卡片与浅色渐变背景。
