# PanelMate PRD

## 1. 文档信息

- 产品名称：`PanelMate`
- 产品定位：面向 `1Panel V2 API` 的移动端管理伴侣
- 文档版本：`V2.6`
- 文档类型：产品需求文档（PRD）
- 目标平台：`iOS / Web`
- 更新日期：`2026-05-04`

## 2. 产品背景

1Panel 当前主要以 Web 形态提供服务器、网站、容器、数据库、文件、备份等管理能力。PanelMate 的目标不是完整复制 Web 后台，而是为多服务器场景提供高频巡检与轻量操作入口。

当前版本统一收敛到 `1Panel V2 API`，不再兼容 V1，也不再提供告警中心与应用内提醒功能。产品信息架构调整为 `概览 / AI / 我的` 三个底部导航入口，其中 `概览` 负责服务器总览与管理主流程，`AI` 负责承接 AI 能力模块展示与扩展。

## 3. 产品目标

### 3.1 核心目标

1. 在一个 App 中接入并管理多个 1Panel 服务器。
2. 提供面向移动端的高频巡检与轻量操作能力。
3. 使用 V2 API 获取实时概览、操作日志与模块数据。
4. 保证账号、API Key、服务器连接信息的安全存储与传输。
5. 为后续 AI 巡检、日志问答、变更建议等能力预留统一入口。

### 3.2 非目标

1. 不完整替代 1Panel Web 后台。
2. 不承载复杂编排、批量变更和大规模配置编辑。
3. 不支持 V1 API。
4. 不提供告警中心、告警聚合和应用内提醒。
5. 当前阶段不提供完整 AI 对话闭环，仅提供 AI 模块入口与展示承载页。

## 4. 目标用户

1. 个人开发者。
2. 小团队运维人员。
3. 使用 1Panel 管理多台云服务器的站长。
4. 需要随时掌握生产环境状态的技术负责人。

## 5. 核心使用场景

1. 查看多台服务器的 CPU、内存、磁盘、网络速率和负载。
2. 在同一概览页内完成搜索定位、状态筛选、列表浏览和进入详情。
3. 快速定位离线或异常服务器并进入详情页查看实时资源与操作日志。
4. 查看容器、网站、应用、数据库、文件、备份模块的运行状态并执行基础操作。
5. 在 AI 工作台查看后续可用的智能巡检、日志问答和变更建议模块。

## 6. 范围定义

### 6.1 当前范围

- 多服务器接入与管理。
- 概览页服务器列表主入口。
- 单台服务器详情。
- 容器、网站、应用、数据库、文件、备份模块入口与列表能力。
- AI 工作台入口与模块展示页。
- 前台轮询设置。
- 内置渐变主题与自定义调色板。
- 本地安全能力。

### 6.2 不在当前范围

- V1 API 兼容。
- 告警中心。
- 应用内提醒。
- 完整的文件编辑器。
- 完整的数据库管理台。
- 复杂部署编排。
- 自建消息推送后端。
- 完整 AI Agent 对话、自动执行和闭环操作。

## 7. 功能需求

### 7.1 服务器接入

1. 支持手动添加服务器。
2. 支持填写服务器名称、地址、协议、端口、备注、标签。
3. 固定使用 `1Panel V2 API`。
4. 支持账号密码登录与 API Key 登录；账号密码登录需兼容 1Panel V2 的 `panel_public_key`、RSA + AES-CBC 加密、session cookie 与 CSRF token 流程。
5. 支持 EntranceCode。
6. 保存前必须执行连接测试。
7. 支持删除服务器。
8. 支持后续补充编辑服务器连接配置能力。

### 7.2 概览页

1. 作为服务器相关操作的主入口。
2. 首屏顶部展示页面标题、状态摘要文案与右上角 `+` 新增按钮。
3. 不再展示独立统计卡片区，不再以内嵌列表项承载新增服务器入口。
4. 搜索框位于标题区下方，优先承载查找操作。
5. 支持搜索服务器名称、地址与标签。
6. 支持 `全部 / 在线 / 离线` 三种列表筛选。
7. 搜索与状态筛选支持组合使用。
8. 展示服务器卡片列表。
9. 服务器卡片展示 CPU、内存、磁盘、健康状态、认证方式、最后同步时间等核心信息。
10. 支持点击服务器卡片进入详情页。
11. 支持通过服务器卡片操作菜单编辑或删除本地连接配置。
12. 支持前台自动轮询刷新。

### 7.3 单台服务器详情

1. 展示顶部健康卡片。
2. 展示实时资源数据。
3. 展示上下行速率与负载。
4. 展示最近操作日志。
5. 提供模块入口。
6. 展示当前接入的 V2 API 能力摘要。

### 7.4 模块能力

1. 容器：列表、状态、统计、日志、基础操作。
2. 网站：列表、状态、证书摘要、基础操作。
3. 应用：已安装应用列表、版本、状态、基础操作。
4. 数据库：数据库列表、状态、基础操作。
5. 文件：目录浏览、文件内容只读。
6. 备份：账户与记录查看。

### 7.5 AI 工作台

1. 底部导航第二个入口固定为 `AI`。
2. AI 页用于承载 AI 功能模块卡片和能力说明。
3. 当前阶段展示智能巡检、日志问答、变更建议等模块入口。
4. AI 页不承担服务器列表、搜索与筛选职责。
5. 后续 AI 能力扩展应优先复用该页面信息架构。

### 7.6 设置与安全

1. 支持应用锁，前台闲置或从后台返回超过设定时间后弹出锁定遮罩，需用户确认才能继续使用。
2. 支持自动锁定时间间隔配置（关闭 / 1 分钟 / 5 分钟 / 15 分钟 / 30 分钟）。
3. 支持后台自动模糊，应用切到后台或任务切换时遮挡敏感信息。
4. 支持应用锁、自动模糊、自动锁定时间持久化存储。
5. 支持前台轮询间隔配置。
6. 支持轮询设置持久化并真实作用于自动刷新。
7. 支持证书信任提示。
8. 支持内置渐变主题选择。
9. 支持在弹出调色板中切换主题。
10. 支持自定义主题，用户可分别选择主色、辅色和点缀色。
11. 支持主题与自定义颜色持久化，重启后保持选择。

### 7.7 视觉主题

1. 默认采用清新毛玻璃视觉风格。
2. 内置主题包括 `薄荷清晨 / 海盐蓝 / 青柠花园 / 晨曦苏打`。
3. 主题影响全局背景渐变、主色、按钮、输入框、底部导航和卡片强调色。
4. 自定义主题根据主色、辅色、点缀色自动生成浅色渐变背景。
5. 主题选择入口位于 `我的 / 设置 / 主题样式`。

## 8. 安全要求

1. 账号、密码、API Key、EntranceCode 使用安全存储。
2. 连接配置与业务数据分离存储。
3. 不本地持久化实时概览与操作日志。
4. 账号密码登录成功后的 `psession` 与 `pcsrftoken` 使用安全存储，后续请求自动携带 `Cookie` 与 `X-CSRF-Token`。
5. 支持应用锁：前台闲置或从后台返回超过设定时间触发锁定遮罩，需用户确认才能继续使用。
6. 支持后台 / 任务切换时自动模糊遮罩敏感内容。
7. 1Panel 账号开启 MFA 时不支持账号密码自动同步，连接测试明确报错并提供一键切换为 API Key 接入。
8. 默认使用 HTTPS。
9. 支持证书指纹记录与提示。

## 9. 非功能需求

### 9.1 性能

1. 概览页在正常网络下 3 秒内返回核心状态。
2. 单台服务器详情在 2 秒内返回基础数据。
3. 至少支持 20 台服务器接入管理。

### 9.2 稳定性

1. 单台服务器不可用不影响其他服务器使用。
2. 前后台切换后可恢复核心状态。
3. 网络抖动时尽量保留上一份有效概览。

## 10. MVP 范围

1. 多服务器接入。
2. 概览页服务器主入口。
3. 单台服务器详情。
4. 容器 / 网站 / 应用 / 数据库 / 文件 / 备份模块基础能力。
5. AI 工作台入口与模块展示。
6. 本地安全能力。
7. 主题样式选择与自定义调色板。
